# ゲーム設計メモ

## 決まっていること

- タイトル: ルナと月蝕の迷宮
- 既存ゲームとは別作品・別公開URL
- ジャンル候補: 入るたびに構造が変わるダンジョンRPG

## 次に決めること

- 主人公ルナの見た目・能力・目的
- 画面向き（縦／横）と対象端末
- 移動方式（ターン制／リアルタイム）
- ダンジョン生成、戦闘、アイテム、成長、敗北時のルール
- アルセーヌから流用する素材と、完全新規にする素材

## 確定仕様：月蝕タイムアタック

### 解放

- B20Fへ初めて到達すると、タイムアタック機能を解放する。
- 解放時に恒久遺物「月蝕の砂時計」を獲得する。
- 解放前の拠点ミッションボタンには「B20F到達で解放」と表示する。

### 発生

- 解放後、帰還して次の潜行へ進む際にタイムアタック発生抽選を行う。
- 「月蝕の砂時計」Lv.1の発生率は25%。
- 遺物強化1段階につき発生率を1%加算する。
- 発生率の上限は40%。
- タイムアタック発生中は再抽選しない。

### 挑戦と報酬

- 挑戦中は制限時間内に到達した階数を記録する。
- 到達階が高いほど、獲得できる恒久アイテムのランクが上がる。
- 到達済みの途中階報酬もすべて獲得する。
- ミッションボタンから制限時間、階層別報酬、現在の到達報酬、次の報酬階を確認できる。
- 具体的な制限時間、報酬階、アイテム内容、ランク区分は別途確定する。
