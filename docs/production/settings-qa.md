# 設定画面の追加検査（2026-09-30）

## 発見と修正

build18で設定画面の実スライダーcallback、音量0からの復帰、値の表示、画面再生成を通し検証へ追加した。390×844で144チェックは成功したが、02b-settings.pngを目視したところ塗りとつまみが縦に伸び、見出しへ侵食していた。

原因はUnity SliderがfillRect/handleRectのYアンカーを0..1へ設定すること。44design px高の親へ直付けしていたため、塗りは44、つまみは44+34=78design pxになった。

build19でSettingsViewのみ修正：塗りを8.8design px高のTrackへ、つまみを高さ0のHandle Railへ移し、アンカー変更でもつまみ34design pxを維持。入力の当たり領域44design pxは変更しない。ルナ・マス・拠点配置・戦闘仕様は変更なし。

ProductionPlaytestへfill高さ10以下、handle高さ34.1以下の4検査を追加。build19の7組ロジック検証とビルドは成功。修正後390画像は見出しとの重なり解消を親が目視済み。通し結果と360画面は下へ追記する。

## 限界

Slider.valueを変更し実callbackとAudioSourceの音量を検査する自動テストで、実マウスドラッグ／iPhoneの指操作や聴感は検査していない。QA音量はメモリ内に隔離される。公式サイト／ライセンスリンクは存在のみ、外部サイトは開かない。

小型画面では画面全体を縮小するため本文も小さくなる。今回の修正は見出し侵食の解消で、設定画面全体のスマホ最終デザインではない。

## 修正後画像の独立目視

画像監査担当が `QA/production-settings390-fixed/02b-settings.png`（390×844）と `QA/production-settings360-fixed/02b-settings.png`（360×640）を閲覧。親報告の390通し結果は148チェック成功。360通し完了はこの目視時点では未確認で、画像のみ判定した。

- 両画面ともBGM23%・効果音42%の見出し/値とつまみの間に空間があり、修正前の侵食は解消。塗りは細い横線、つまみは独立した短い矩形となっている。
- 設定タイトル、説明文、操作ガイド3行、クレジット2行、外部リンク2個、戻るボタンに文字切れ・見た目の重なりはない。意図しない追加改行も見えない。OtoLogicとCC BY 4.0の表記を読み取れる。
- 360画面の左右黒帯は縦横比保持によるもの。戻るボタンも下端まで収まる。ただし本文・副説明は小さく、読みやすさは390より低い。画面内に収まることと小型端末で快適に読めることは同義ではない。

今回の2枚に重大な描画不具合は認めなかった。0%/100%位置の実画像、ドラッグ操作、実機safe-area、外部リンク遷移、音量の聴感はこの静止画検品に含まない。コード・素材・拠点レイアウト・Unity状態の変更なし。
