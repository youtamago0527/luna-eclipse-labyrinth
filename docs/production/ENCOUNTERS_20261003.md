# 敵配置と難易度更新 2026-10-03

## 変更
旧: 全階3体、遠い敵は停止、自然増援なし。
新: `EncounterDirector`に配置・抽選・自然増援・徘徊を分離。移動/攻撃の8方向と壁角禁止、既存のアイテム/遺物/レベル仕様は保持。

|階|初期数|同時存在上限|増援間隔|
|---|---|---|---|
|B1|6〜8|12|64行動|
|B3|7〜9|13|64行動|
|B5|8〜10|14|64行動|
|B10|10〜12|16|56行動|
|B13|12〜14|18|48行動|
|B21以降|12〜14|18|32行動|

- 初期は各部屋に分散、その後の巡回で同部屋に複数体配置。開始部屋は最大1体、開始位置からマンハッタン距離5以上。床/階段/アイテム/他の敵との重複チェック。
- B1〜2の種別比率はスライム60/コウモリ30/ゴースト10。B3〜5でキノコ、B6以降ミミック/ゴーレムを解放。深層で弱い敵だけに戻る循環を廃止。
- 生成敵の攻撃力を従来カタログ値+1、4階ごとの深度補正（HP最大+30、攻撃最大さらに+10）。敵基本データを利用する単体テストには影響を与えない生成時補正。
- プレイヤーを認識していなければ50%の確率で合法な隣マスへ徘徊。認識後は既存の追跡。ルナ/敵の重なり・壁角すり抜けは禁止。
- 自然増援は視界外かつマンハッタン距離12以上のみ。敵全滅後も有効。配置可能マスがなければその回は見送る。敵行動の後に出現し、そのターンに攻撃しない。上限あり、一意IDを維持。
- 増援時計は階ごとにリセット。失敗入力やメニューで進まない。通常プレイは常に有効。旧機能の隔離テストだけ `AmbientEncounters=false` にして意図しない増援を止める。新しい配置テストと戦闘シミュレーションは有効のまま行う。
- モンスターハウス、罠、新しい敵素材/特殊能力は今回追加していない。
