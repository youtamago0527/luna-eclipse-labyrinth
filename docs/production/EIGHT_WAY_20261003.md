# 8方向・冒険レベル・自然回復・足踏み（2026-10-03）

## 仕様
- ルナと敵が8方向移動・隣接攻撃。斜めの両脇どちらかが壁なら移動も攻撃も不可。1マス1ターン。生成と接続検証は従来の4方向を維持。
- PC: 矢印/WASDの2方向同時押し。スマホ: 8方向ボタンの長押し。
- Lv.1開始、冒険終了後は引き継がない。討伐EXP=max(2,敵最大HP/2)。累積EXP=5×Lv×(Lv−1)、上限30。レベル毎最大HP+2/現在HP+2、2レベル毎基礎攻撃+1。恒久ステータス強化ではない。
- 5回の成功した行動につきHP+1。敵行動の後に処理。HP上限・死亡・満腹0を考慮。壁への入力や整頓、メニュー操作は対象外。階段の1ターンも対象。
- パッド中央「足踏み／長押し」でその場の連続ターン。各ターン敵も動く。満腹度は通常と同じターン基準で減るので、時間当たりの消費が速い。HP満タン、満腹10以下、視界内または3歩以内の敵、指を離す/ボタン外へ出す、別移動、モーダル、アプリ中断で停止。自動回復アイテム使用はしない。
- 装備詳細に武器攻撃力/盾防御力の基礎1・強化・合計を表示。未鑑定の強化と合計は「?」で漏らさない。バッグに現在の総攻撃/防御、上段にLvと次LvまでのEXP。
