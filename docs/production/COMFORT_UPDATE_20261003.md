# 2026-10-03 操作・持ち物改善

ユーザー指示: 一歩移動ログ不要、長押し移動、自動拾得、整頓、10枠×2ページ、装備強化値の未鑑定、低確率マイナス装備と呪い、ダンジョンBGM。

## 実装

- 歩行だけのログを削除。戦闘・拾得・階段・満杯等の通知は残す。
- 方向パッドは押した瞬間に1歩、0.28秒後から0.16秒間隔で入力。既存ターンロックを通し、同時移動しない。指を離す／ボタン外へ出る／モーダルを開く／フォーカス喪失・中断で保持解除。PCのWASD/矢印も保持移動。
- マスへ移動すると足元の品を自動取得。追加ターンなし、歩行アニメーション維持。満杯なら品を床に残す。床に置いた直後は拾い直さず、一度離れて戻るか既存「拾う」を使う。
- 持ち物は1ページ10枠、通常20枠で2ページ。バッグ拡張遺物の既存20〜40枠を削除せず追加ページで扱う。
- 「整頓」は武器→盾→薬草→巻物→その他。同種は名前・ID順。未鑑定の強化値でソートせず値を漏らさない。整頓はターン消費なし、装備ID維持。
- 一覧から品を選び、詳細で装備／使用／床置きする。
- 武器・盾は拾得時に強化値非表示（[?]）。暫定の識別タイミングは装備時。識別状態は帰還・倉庫・持込へ保存。旧保存の識別フラグ欠落は未鑑定として安全に読む。
- 元の装備生成抽選をマイナス5%、非マイナス95%に変更。マイナスは-1〜-3、通常は0〜+3。その後に既存遺物補正を加算するため、補正があると最終マイナス率は下がる。設定はDungeonRules.NegativeEquipmentPercent。
- 最終強化値がマイナスの武器・盾は呪い扱い。装備すると交換・床置き不可。拒否はターン消費なし。解呪や追加ペナルティは未実装。
- 未装備の呪い装備は床置き可能。帰還で装備状態をリセットする従来の流れは維持し、次回再装備すれば再び拘束される。マイナス値自体は消さない。
- 既存の正式DL済み探索曲をダンジョン遷移時に即座に再生開始。10階以降は深層曲。BGM音量0の設定は尊重し、勝手に解除しない。
