# ルナと月蝕の迷宮 — 朝の試遊案内

2026-09-30、Unity Windows試遊版 build20。商用完成版ではありません。

## まず遊ぶ

Windows ZIPをすべて展開し、LunaEclipseLabyrinth.exeを起動してください。DataやDLLを移動せず一緒に置きます。タイトル→冒険をはじめる→迷宮へ→探索を始める、で開始します。詳細操作はZIP直下のPLAY_GUIDE.mdです。

- 矢印／WASDまたは方向ボタンで移動。敵に向かって移動、またはSpace／J／攻撃ボタンで攻撃。
- E／拾うで床アイテムを拾い、持ち物から装備・HP回復・置く。
- 階段に乗って階段ボタンで次の階。上部の拠点から帰還、倉庫で次回の持込品を選択。
- 終了前は拠点へ帰還してください。途中終了では新規拾得品やマップ状態は保存されません。元の持込品は復元します。
