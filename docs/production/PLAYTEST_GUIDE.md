# 試遊のしかた（Windows）

1. Windows版ZIPを**すべて展開**し、`LunaEclipseLabyrinth.exe`を開きます。exeだけを別の場所へ移さず、同梱のDataフォルダーやDLLと一緒に置いてください。
2. タイトルの「冒険をはじめる」→拠点の「迷宮へ」→開始階を確認して「探索を始める」。最初はB1Fです。
3. 矢印キー／WASD、または画面の上下左右で1マス移動します。敵のいる方向へ進むと攻撃します。「攻撃」またはSpace／Jでも攻撃できます。
4. アイテムの上に立ち「拾う」を押します。「持ち物」を開き、剣・盾は「装備」、薬草・回復薬はHPが減ったときに「使う」。満腹度は回復しません。
5. 階段を探し、その上で「階段を降りる」を押します。HP・満腹度・バッグを引き継いで次の階へ進みます。
6. 上部の「拠点」から帰還します。結果画面で持ち帰り品を確認し、「倉庫」へ。次も使う品は「持込選択」で選び、拠点から再出発してください。持込品はバッグから装備・使用できます。

拠点の設定画面でBGM・効果音の音量を調整できます。「待機」はピリオドキーでも操作できます。右上のミニマップを押すと地図を拡大します。

## 試遊時の注意

- 終了前は拠点へ帰還してください。**探索途中で終了すると、その探索で新しく拾った未確定品や進行状態は保存されません。** 倉庫から持ち込んだ元の品は再起動時に復元します。
- 倉庫が満杯でも持ち帰り品は「保留」に保存されます。倉庫で整理して回収できます。
- 遺物の20階ごとの獲得機会は記録しますが、通常報酬は**調整待ち**です。現段階では自動で遺物が付与されません。
- 買い物・ミッション・図鑑などは準備中です。iPhone実機は未検証で、今回はWindows試遊版です。
- 保存失敗の表示が出たら、アプリを閉じず空き容量などを確認し「保存を再試行」を押してください。

不具合を伝えるときは、操作内容・階数・画面写真・使ったZIP名を添えてください。Windows版ZIPでは詳しい現状を`Documentation/README.md`と`Documentation/docs/production/OPEN_ITEMS.md`で確認できます。UnityソースではルートのREADMEと`docs/production/OPEN_ITEMS.md`にあります。
