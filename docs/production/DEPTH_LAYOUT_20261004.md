# ルナ20%拡大・階層別マップ（2026-10-04）

## 表示
- ルナの本体目標高を0.85→1.02マス（+20%）。上下左右/斜めの全表示に共通のスケール。
- 足元ピボットと座標オフセット、9マス幅カメラ、1マス移動/当たり判定、敵の大きさは変更しない。PNG素材の拡大加工も不要。
- 頭や髪がマスより少し上にはみ出すことを許容。大きくなったため完全な非重複は意図していない。近接した敵の判別を画面確認する。

## 階層別設定
|階層|区画|部屋数|通常の部屋サイズ|追加接続|行き止まり枝の目標数|
|---|---|---|---|---|---|
|B1〜4|月影の遺跡|5〜7|幅5〜7 / 高5〜8|0|3|
|B5〜9|蒼月の回廊|7〜9|幅4〜6 / 高4〜7|2|4|
|B10〜14|紫晶の広間|5〜7|幅7〜10 / 高7〜10|1|3|
|B15〜19|月鎖の獄|8〜9|幅4〜6 / 高4〜6|3|5|
|B20以降|月蝕の深淵|6〜9|幅4〜10 / 高4〜11|3|6|

- 初期部屋だけは全階層で幅5〜7/高5〜8。総マップ39×45は維持。階層とseedで再現可能な乱数生成。
- 最寄り部屋への接続で連結性を確保し、その後に別の部屋同士の接続を追加。既存経路と重なる場合もあるため追加接続数は独立ループの厳密な個数ではない。
- 通路は1マス幅を維持。行き止まり枝は隣接する床を潰さず作れる場所だけに追加するため、目標数より少ない場合がある。
- 階段は開始地点から歩行距離の遠い部屋の中心。部屋/通路のFog of Warとミニマップは既存仕様のまま。
- 既存の石床/壁画像をそのまま使用。区画ごとに青/紫等の控えめな色調とひび割れ床の比率を変える。新しいタイル素材やギミック、罠は追加していない。
- 降りる度に新しい地形になる。5階ごとに傾向が切り替わり、B20以降も混合型で毎階再生成。
