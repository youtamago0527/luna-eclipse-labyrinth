# ルナ正式スプライト

実装先：ルナの不思議なダンジョン。2026-09-08更新。

- `source/official.png`：提供された「ルナポリゴンキャラ絵.png」の変更していないコピー。
- `walk/`：原本の歩行4方向×4枚。各コマの範囲を個別指定して切り出したもの。
- `idle/`：各方向の歩行1枚目を静止画として使用。歩行開始・停止時の絵柄と大きさを揃えるため、正面だけ別サイズの専用待機絵には切り替えない。
- `attack/down_*.png`：原本の剣攻撃3枚。
- `attack/left_*.png`, `right_*.png`, `up_*.png`：ユーザーの「ない画像は作っていいよ」の指示により追加生成した各3枚。原本からの切り出しではない。原本との衣装細部・筆致には差がある。
- `source/attack-*-generated.png`：採用した生成画像。built-in image_gen使用。正確な生成プロンプトは `generation-prompts.json`。

ゲームは32枚の個別PNGだけを読み込む。原本、生成用ストリップ、一覧画像をスプライトシートとして直接描画しない。

全PNGは320×240、キャラクター基準X=160、足元基準Y=216。武器・髪・軌跡の大きさに合わせてフレームごとに表示倍率を変えず、全動作で同一倍率を使用する。原本歩行は拡縮せず、別サイズの原本攻撃・生成素材は切り出し工程で方向内共通倍率に縮小した。原画の歩幅・髪の揺れは残している。

`tools/extract_luna.py` で再生成可能（Python、Pillow、NumPyが必要）。個別の切り出し範囲・中心・足元・倍率は `extraction.json` に記録。暗い原本背景は外側から除去し、黒い衣装に穴が開かないよう輪郭の小さな隙間を閉じてから透過判定する。追加生成素材は緑背景を透明化している。

原本の使用範囲では、隣接キャラ・文字・罫線・分離不能な重なりは見つからなかった。最初に生成した左攻撃は背景に市松模様が描き込まれたため不採用にし、作り直した。採用フレームの一覧は `contact-sheet.png`。
